# Промпты для Nano Banana: аватар и баннер МАРСИ-Job

## Стилистика бренда (единый блок для всех промптов)

Позиционирование: **«не поиск работы, а совпадение»** — детерминированная математика подбора + человечное тепло. Визуальный язык — граф из узлов и рёбер (атомарные факторы МАРСИ), созвездия, точные светящиеся линии, формула как артефакт.

Палитра (вставляется в каждый промпт для консистентности):

- фон: глубокий индиго-градиент `#1E1B4B → #4C1D95`;
- тёплый акцент (человек/кандидат): янтарный `#F59E0B`;
- холодный акцент (вакансия/точность): циан `#22D3EE`;
- текст/линии: белый и светло-серый `#E5E7EB`.

Смысловая логика: янтарная точка = кандидат, циановая = вакансия, светящаяся линия между ними = матч (скор). Эта пара узлов — фирменный знак во всех носителях.

Избегать (добавляйте в конец каждого промпта): `без рукопожатий, портфелей, луп, офисных фотографий, без стоковой корпоративной эстетики, без водяных знаков`.

Практические советы:

1. **Аватар**: Telegram обрезает его в круг → ключевые элементы в центральной зоне ~70% площади, фон до краёв. После генерации проверьте читаемость в размере 40×40 px.
2. **Кириллица**: Nano Banana часто искажает русские буквы. Надёжный путь — генерировать баннер с чистыми зонами под текст и накладывать шрифт в Canva/Figma (шрифты: Golos, Inter, Montserrat). Промпты ниже дают оба варианта: с текстом и без.
3. Генерируйте 3–4 варианта каждого концепта, отбор — по читаемости в мелком размере, а не по красоте в большом.

## Аватар (1:1, все — без текста)

### Аватар 1 — «Граф-созвездие М» (основной концепт)

> Квадратная иконка 1:1 для Telegram-бота, минималистичный плоский вектор со лёгким свечением. Фон — глубокий индиго-градиент от #1E1B4B к #4C1D95, заливает весь квадрат до краёв. В центре — абстрактная буква «М», собранная из тонких светящихся белых линий-рёбер графа и маленьких круглых узлов в вершинах. Два узла крупнее и ярче остальных: тёплый янтарный #F59E0B в левой «ножке» М и циановый #22D3EE в правой; их соединяет светящаяся линия через центральную вершину. Вокруг буквы — 5–7 маленьких приглушённых узлов-звёзд, как созвездие. Всё композиционно вписано в центральную зону под круговую обрезку. Без текста, без водяных знаков, без рукопожатий, портфелей, луп, офисной стоковой эстетики.

### Аватар 2 — «Атом МАРСИ»

> Квадратная иконка 1:1, минималистичный flat-вектор. Глубокий индиго-градиентный фон #1E1B4B → #4C1D95. В центре — стилизованный атом: две наклонные эллиптические орбиты из тонких светящихся линий образуют абстрактный силуэт буквы «М»; в ядре — мягко светящийся белый узел; по орбитам — 4–5 маленьких электронов-точек, одна электрон-искра крупная, янтарная #F59E0B, с лёгким свечением. Вторая акцентная точка — циановая #22D3EE на противоположной орбите. Магия точной науки, спокойная, чистая композиция, элементы в центре под круговую обрезку. Без текста, без водяных знаков, без корпоративных штампов.

### Аватар 3 — «Монограмма-узел» (app-icon стиль)

> Квадратная иконка 1:1 в стиле современного app-icon: скруглённый квадрат с индиго-градиентом #1E1B4B → #4C1D95 и едва заметной сеткой из тонких линий на фоне. Внутри — жирная геометричная монограмма «M», нарисованная одной ломаной линией, как маршрут на карте; в двух вершинах ломаной — круглые узлы: янтарный #F59E0B слева и циановый #22D3EE справа, оба с мягким свечением; между узлами по линии — маленькая светящаяся точка-искра матча. Плоский вектор, смело, чисто, узнаваемо в размере 40×40 px. Без текста, без водяных знаков, без стоковой офисной эстетики.

## Рекламный баннер (16:9, 1280×720)

### Баннер 1 — «Совпадение» (основной, с текстом)

> Широкоформатный рекламный баннер 16:9 для Telegram-бота подбора работы. Фон — глубокий индиго-градиент #1E1B4B → #4C1D95 с лёгкой звёздной пылью из мелких точек-узлов. Слева — абстрактный силуэт человека, собранный из светящихся янтарных #F59E0B точек-узлов и тонких линий, как созвездие. Справа — абстрактный силуэт здания рабочего места из циановых #22D3EE узлов и линий. Между ними по центру — яркая светящаяся соединительная линия, а на ней крупная цифра «0.87» с мягким свечением, как результат вычисления. Вверху крупный белый заголовок: «Не поиск работы. Совпадение.» Ниже строки сцены — подзаголовок светлым серым: «Подбор по формуле: десятки факторов, честный скор, объяснение каждого матча». Внизу справа — маленькая плашка с текстом «@MarsiJobBot». Стиль: технологичный, тёплый, точный; flat-иллюстрация со свечением. Без рукопожатий, портфелей, луп, офисных фото, без водяных знаков.

**Вариант без текста** (если кириллица ломается): замените последний абзац на: «Вверху оставить чистую широкую зону под заголовок, внизу — маленькую тёмную плашку-подложку справа; текст наложить позже».

### Баннер 2 — «Карта факторов» (объяснимость)

> Рекламный баннер 16:9. Фон — тёмный индиго #1E1B4B с тонкой технической сеткой. Слева — светлая полупрозрачная карточка-профиль кандидата: аватар-созвездие из янтарных #F59E0B узлов и 5 горизонтальных полос-факторов разной длины, некоторые подсвечены. Справа — такая же карточка вакансии с циановыми #22D3EE элементами. Между карточками — 3–4 тонкие светящиеся линии, соединяющие одинаковые полосы факторов, в местах соединения — маленькие искры. В центре между карточками — круглая метка с надписью «0.82». Внизу по центру белый заголовок: «Почему эта работа подходит — с точностью до фактора», ниже серым: «МАРСИ-Job объясняет каждый матч». Стиль: UI-иллюстрация, чистая геометрия, свечение, доверие. Без стоковой корпоративной эстетики, без водяных знаков.

### Баннер 3 — «Формула» (для tech-аудитории)

> Минималистичный рекламный баннер 16:9, почти весь — глубокий индиго-градиент #1E1B4B → #4C1D95. В центре крупно, как неоновая надпись с мягким свечением, формула: «SCORE = Σ Match + Φ − r». Символ Φ выделен янтарным #F59E0B, остальные знаки — белые с циановыми #22D3EE акцентами на плюсах и минусах. Под формулой — тонкая светящаяся линия с двумя узлами: янтарным и циановым, соединёнными искрой. Ниже двумя строками: белым «Математика подбора, которая объясняет свой ответ», серым мельче «работа, где ты приживёшься». Внизу справа маленькая тёмная плашка с «@MarsiJobBot». Стиль: сдержанный, инженерный, премиальный. Без стоковых клише, без водяных знаков.

## Порядок работы

1. Сгенерируйте Аватар 1 (основной концепт) в 4 вариантах → выберите лучший на 40 px → им же вдохновитесь для баннеров (единый знак «два узла + линия»).
2. Баннер 1 — для широкой аудитории каналов о трудоустройстве, Баннер 2 — для сторис о «честном скоринге», Баннер 3 — для IT-аудитории (Хабр, джун-каналы).
3. Если текст в кириллице вышел кривым — берите no-text вариант и накладывайте шрифтом; формула в Баннере 3 латиницей/символами обычно рендерится надёжно.
