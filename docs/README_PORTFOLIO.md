Двусторонний матчинг-сервис (кандидаты ↔ работодатели) в Telegram. В отличие от
традиционных джоб-бордов, ранжирование **не нейросетевое** — детерминированный
движок на основе метода МАРСИ (Метод Атомарного Разделения и Сопоставления
Информации): каждый фактор имеет вычислимый вес, синергии и конфликты
описываются матрицей взаимодействий, а результат объясним по построению.

## Почему это интересно

| Традиционный подход | МАРСИ-Job |
|---|---|
| LLM-ранжирование (чёрный ящик) | Детерминированная формула: `SCORE = (Σ match·W − Σr + ΣΦ) / ΣW − ε` |
| «Вам подходит» без причин | Карточка: «+31% стек совпадает, +18% удалёнка, −7% нужен +1 навык» |
| Фильтры по ключевым словам | 32 фактора: от хард-скиллов до нейроособенностей и сенсорной нагрузки |
| Позиция в выдаче продаётся | Платные продукты **не влияют** на скор — только аналитика и охват |

**Ключевой принцип:** LLM используется только как парсер (текст → JSON) и
генератор вопросов для мок-интервью. Все скоры, веса, ранжирование — чистая
математика, воспроизводимая и объяснимая.

## Функциональность

### Кандидату
- **Анкета** — быстрый старт (8 инлайн-вопросов) или голосовое сообщение
- **`/match`** — топ-3/20 матчей с разбором каждого фактора
- **`/why`** — зона валентности: первопричина, почему не зовут
- **`/audit`** — аудит резюме 0–100 по 7 измерениям
- **`/interview`** — мок-собеседование с ИИ (STAR-разбор ответов)
- **`/roadmap`** — план «+X очков» на 3 месяца
- **`/referral`** — +7 дней Plus за каждого друга после его анкеты

### Работодателю
- **`/post`** — публикация вакансии с авто-модерацией (ТК РФ)
- **`/search`** — топ-5 кандидатов со скором совпадения
- **`/invite`** — приглашение (с согласия кандидата)
- **`/broadcast`** — таргет-рассылка топ-100 совместимым
- **`/deep`** — углублённый анализ (в Pro)

## Математическое ядро (МАРСИ)

```
W_n   = w₀ · (wₜ·t + wₘ·m + w𝒻·f + wₑ·e + wᵧ·y + w₉·g + wₕ·h) · R_obj + εₙ
SCORE = (Σ matchₙ·Wₙ − Σ rₙ + Σ Φⱼₖ) / Σ Wₙ − ε
```

- **W** — вес фактора (7 параметров × 32 фактора)
- **match** — близость кандидат↔вакансия (0..1)
- **r** — ресурсозатраты на сближение (релокация, обучение)
- **Φ_jk** — матрица взаимодействий: синергии >0, конфликты <0, блокировки =−∞
- **ε** — энтропия (неизвестные данные, «отклики без ответа»)

Полная трассировка на документ-первоисточник: [spec/SPEC.md](spec/SPEC.md).

## Разработка

Проект разрабатывался с помощью ИИ-агентов (GLM-5.3) по детальным
техническим спецификациям. Промпты-спецификации доступны в
[docs/prompts/](docs/prompts/) — они демонстрируют подход к управлению
ИИ-разработкой: чёткие контракты, ограждения («ядро не трогать»),
критерии приёмки.
